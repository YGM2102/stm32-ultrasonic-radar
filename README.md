# STM32 超声波倒车雷达

基于 **STM32F103C8T6** 的倒车雷达：HC-SR04 超声波测距 + SSD1306 OLED 实时显示 + 蜂鸣器分级报警 + 按键切换档位。

全部代码在面包板上搭出来后烧录验证，`main.c` 为**自写版**，并修复了参考工程的三个缺陷。

## 硬件连接

| 外设 | 引脚 | 配置 |
|---|---|---|
| HC-SR04 Trig | PA6 | 推挽输出 |
| HC-SR04 Echo | PA7 | 下拉输入（串 1K 限流） |
| 蜂鸣器模块 | PB12 | 推挽输出，S8550 驱动，**低电平响** |
| 按键 | PB13 | 上拉输入 + EXTI13 **下降沿**（另一端直接接 GND） |
| OLED SSD1306 | PB6 = SCL / PB7 = SDA | **软件 I2C** |
| 板载 LED | PC13 | 开机自检 + 报警跟随（低电平亮） |

## 相比参考工程（PDD）修掉的三个缺陷

1. **测距死等** —— 原版两段等待回波都没有超时，超声波模块一没接上主循环就卡死
   → 加入 DWT 超时：上升沿等待上限 **30ms** / 回波脉宽上限 **24ms**，超时判为无效距离
2. **按键悬浮** —— 原版 `NOPULL` 输入悬浮、模式乱跳
   → 内部上拉（IPU）+ 外部 1K 接地，改用 **EXTI13 下降沿**
3. **报警阻塞** —— 原版用 `HAL_Delay` 阻塞主循环，拖慢测距刷新
   → 改成 DWT 毫秒计数做**非阻塞翻转**，节拍 `100 + 距离 × 20 ms`（距离越近滴滴越急）

## 关键技术点

- **DWT 周期计数器量脉宽**：`DWT_CYCCNT` 每个内核时钟周期 +1，72MHz 下精度约 **14ns**，
  比"循环数次数"准得多。DWT 是 Cortex-M3 内核部件，标准外设库没有封装，寄存器用裸地址宏访问。
- **OLED 软件 I2C 修复**：原例程**缺第 9 个应答时钟**且时钟偏快
  → 补上应答时钟（应答那一拍 SDA 切输入开内部上拉）、`I2C_Delay` 空转 10 → 40。

## 调试方法（可复用）

- **独立 OLED 自检程序**：不依赖 `OLED.c`，自带软件 I2C，自动扫描 PB4~PB9 所有
  (SCL, SDA) 组合 × 地址 `0x78`/`0x7A`，用 PC13 灯报数
- **接线自检**：PB6/PB7 依次配成下拉输入再读（模块自带 4.7k 上拉强于 MCU 内部 40k 下拉）。
  报数规则：**1 下 = 两根都不通 / 2 下 = 只有 PB6 通 / 3 下 = 只有 PB7 通 / 4 下 = 两根都通**
  —— 靠这个定位到"杜邦母头没插到底"
- **OLED 实时电平显示**：把按键引脚实时电平和 EXTI 中断次数直接显示在屏上，
  一眼分离三层故障：电平不变 = 硬件（线 / 开关 / 极性）；
  电平变但中断次数不涨 = EXTI / NVIC；中断涨但模式不变 = 主循环 / 消抖
